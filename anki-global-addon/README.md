# Anki 全局划词收词

这是现有 Zotero 划词同步项目配套的 Anki 桌面端附加组件。Anki 运行时，它可在 Windows 其他应用中捕获选区，并通过 AnkiConnect 写入 Anki；不需要另外安装 .NET 或常驻托盘程序。

## 安装

在 Anki 中通过“工具 → 附加组件 → 从文件安装”选择 `zotero_global_capture.ankiaddon`，或双击该文件安装。也可以将 `zotero_global_capture` 文件夹复制到 Anki 用户配置目录下的 `addons21`，例如：

`%APPDATA%\Anki2\addons21\zotero_global_capture\__init__.py`

重启 Anki。在“工具”菜单打开“全局划词入 Anki 设置…”。设置页可点击快捷键框并录入自定义组合键；至少需要 Ctrl、Alt、Shift 或 Win 中的一个。支持字母、数字、F1–F24 和常用导航键。保存后会立即重新注册。需要 AnkiConnect 正在运行（默认地址 `127.0.0.1:8765`）。如果未安装且没有可用连接，组件会通过 Anki 自带的 AnkiWeb 下载器自动安装官方 AnkiConnect；首次安装完成后需要重启 Anki。已有安装不会被覆盖或强制启用。

## 三种收词方式

- **选中后按快捷键添加**：在任意可复制文本中选择单词或短语，按设置页中的快捷键（默认 `Ctrl+Shift+F10`）。
- **选中后自动添加**：设置为自动模式；鼠标拖选结束时尝试复制并添加。此模式会监听全局鼠标拖选，可能与拖动界面元素冲突；受保护或禁止复制的应用无法捕获。
- **快捷键预览释义，再按一次添加**：默认模式。选中文本并按快捷键后显示释义预览，再按一次快捷键或点“添加到 Anki”确认；取消、关闭或超时都不会添加。

捕获选区需要临时模拟 `Ctrl+C`。组件会暂存并尝试恢复剪贴板内容；某些应用自定义格式或同时有其他程序更新剪贴板时，无法保证所有剪贴板格式和所有应用行为完全一致。选区只向有道词典查询单词释义，文献上下文不会发送。

默认写入牌组“文献单词”、笔记类型“四六级单词模板”，正面字段“正面”、释义字段“解释”。支持的同名可选字段会补入词性释义、例句、权威例句、词根、近义词、音标和发音链接；已有非空字段不覆盖。重复收录会更新“全局划词收录次数”，并给笔记加上 `anki_global_capture` 标签。

## 单词随身复习

Anki 在后台运行时，附加组件默认每 30 分钟在屏幕右下角弹出一张单词卡。它会从当前词组覆盖的牌组里取卡（受各牌组当日额度限制）。**取卡顺序是每组混排**（2026-11-06 定）：每组前 20 %（向下取整，10 张一组就是前 2 张）给已经到期的旧卡，其余给今天的新卡；旧卡不足或新卡额度用完时自动让位。改这条的原因很具体：实测某天有 365 张新卡额度、250 张卡在 Anki 的**学习步**里、27 张成熟复习，而 11-05 的"新词优先、学完当天再复习"会把学习步压到约 37 组之后——10 分钟的学习步因此变成明天。到期队列内部仍按现有的抽取权重与抽样取卡，**不保证"最急的那张最先"**——这是已知取舍：混排解决的是"旧卡完全轮不到"，而"按到期时间严格排序"会跟收录词加权冲突，需要单独决定。默认补充牌组为“四六级单词”（不存在时跳过），可在设置中修改。收录过的词及其他牌组中同词的卡片获得更高抽取权重，收录词的抽取权重上限为普通词的 2 倍；权重不会改变 Anki 的到期时间。默认每 5 分钟额外检查 Anki 的到期队列，若有到期词会提前提醒；新词仍按正常间隔出现。这项“记忆复习”可在设置中关闭。默认每轮连续复习 3 张，可改为 1–999 张，也可让插件按每日目标与剩余量自动分组；选择题支持英文选中文和中文选英文，填空支持释义拼写和有合适例句时的例句挖空。拼写题每个字母一个输入格，输入时即时显示对错；可逐步增加字母提示并继续尝试，点击“显示答案”才揭晓。选择题显示明显的正确或错误反馈。**题目面听发音**：英文选中文和单词释义判断的题面上，单词旁边有一个圆形喇叭，按回车同样生效——单词本来就印在题面上，所以听它**不计入提示、不影响建议评分**；中文选英文的题目面故意不给发音，因为那里要拼的英文单词就是答案。答案面揭晓时仍按「朗读音量」的设置自动读一遍。每张卡核对后选择“再练一次”“困难”“记住了”或“很容易”，结果才写入 Anki；关闭或选择“稍后再说”不会评分。

**拼写与听写题的控件排布**（2026-11-06 重排）：字母格下面一行是**工具**——`释义`、`音标`（仅听写题，且这个词有音标字段时）、`字母 0/9`（已给几个 / 一共几个），都是**描边小按钮**（卡片默认按钮矮一号、12 px 字）；再下面一行只有 `检查拼写` 这一颗实心按钮，居中，和单词、字母格在同一条轴上；`显示答案` 与 `稍后再说` 这两条"不做了"的路一起放在最底下，是文字态，离主动作最远——以前 `显示答案` 紧贴 `检查拼写`，误点一次就把这题判成 Again。原先那句「点击下方“释义提示”查看中文」删掉了：按钮自己说清楚了，底部只留一行按键提示（听写题「回车重听 · 空格给字母 · Shift+空格给音标」）。

> 这三个控件在 11-05 的样片里是纯文字：用户当时选的是**布局**，不是样式；真机用了一轮之后他反馈「看不出来是按钮」，所以 11-06 改回描边按钮——层级靠"填不填充"区分，不靠看不见。

**字母格里没有文本光标**（2026-11-06）：空着的居中格子会把光标画在正中间，而空格提示给的字母也画在正中间，两者叠在一起就看不清给的是哪个字母。这套 Qt 的 QLineEdit 既没有 `setCursorWidth`，`caret-color: transparent` 也只被解析不被执行（实测有无它光标照画），所以做法是绘制时把那一列用格子自己的底色盖掉，改由**格子边框呼吸**（530 ms 一亮一暗，永不完全消失）表示"在这儿打"。翻页、翻面、卡片隐藏都会停表。

在“工具 → 全局划词入 Anki 设置…”可以从已有牌组、笔记类型和字段的下拉菜单中选择配置，也可以暂停提醒，调整间隔、每组数量、位置和题型，设置单词及普通、权威或全部例句在揭晓后自动朗读，开关 Anki 内单词卡美化，以及选择 Windows 登录时启动 Anki 后台复习。该开机启动选项默认关闭；启用后仅为当前 Windows 用户添加启动项，关闭选项会移除它。也可以通过“工具 → 单词随身复习 → 立即弹出一张”随时打开复习卡。

桌面卡片样式只作用于设置中指定的牌组和笔记类型，不修改 Anki 笔记类型或其他牌组的模板。弹窗需要 Anki 和 AnkiConnect 运行；缺少释义的卡片不会被用作选择题或填空题。

单词默认在答案揭晓后自动朗读；例句可选择逐句或全部手动朗读，也可选择自动朗读普通例句、权威例句或全部例句。发音使用 Anki 的系统文字转语音（TTS），不下载 MP3；可用声音取决于系统和 Anki。Anki 本身没有音量设置，插件因此提供“朗读音量”：100% 表示什么都不改；高于 100% 时，插件会用同一套系统语音把单词重新录一遍，然后**提亮 2–4 kHz 的人声频段、让出 180 Hz 以下**（视频和音乐的能量主要落在低频），再做峰值归一——所以单词是“听得更清”而不是一味更响；压缩强度随旋钮温和上升，上限经过实测、不产生削波样本。只影响插件朗读的单词和例句，不改动你自己牌组的音频。设置页可边拖边生效、点“试听”当场听，退出 Anki 后自动恢复，不写任何配置文件。到期时间与评分继续使用用户现有的 Anki 排程，插件不会擅自启用 FSRS 或修改其他牌组的设置。

复习卡右上角的“...”可打开设置、查看评分机制和访问 Zotero 配套插件介绍。例句中的英文单词可点击查询、添加或查看已有卡片；已收录词可选择下划线、加粗或不标记。

拼写题带动效，设置里两个开关各管一件事：**「拼写时字母跳动」**——打对字母在原格子里轻轻跳一下，打错左右抖一下；**「答对时弹出庆祝特效」**——一次写对（没用提示、没有错字母）时弹出金色立体庆祝字（UNBELIEVABLE / PERFECT / GREAT / NICE，按档位分级）。庆祝窗内**只有这一个英文等级词，不出现汉字**；卡片本身的「回答正确」和建议说明行照常是中文，它们不属于庆祝特效。装饰按档位递增：最高档有三星、放射光、五处闪光和大光晕，往下依次减到只有字、缎带和宝石。答错不弹任何庆祝，其他题型也不弹。两个开关互不影响：只关庆祝，字母照样跳；只关跳动，答对仍然弹徽章。

动效是透明的：只画形状本身，四周一个像素都不覆盖。庆祝字的位置由**避让规则**决定（2026-11-05）：卡片先报出自己哪几排不能被压——正在被庆祝的单词（题目面的字母格与答案面的单词行）、"回答正确"那行、依据行、评分按钮排——徽章就落在剩下那条**最高的空白带正中**，空白带不够高就整体缩小（不低于 55%），绝不压上去。旧写法是按卡片高度乘一个固定分数，那个数翻过四次，最后一次在真机上只比单词行低 2 px——是运气不是规则。在典型的 526×630 答案面上，新规则给出的位置是 y=305（卡片中心是 y=315），肉眼几乎同一处，但这条位置现在由内容决定并由像素检查守着：单词行在庆祝期间与无庆祝时逐像素相同，四档都不许出现一个变化像素；它遮住的是解释框和例句框的一部分，动画一结束立刻恢复原样。彩纸从单词行下沿开始飘落，不再从窗口外穿过单词。整段最长 0.98 秒（进 0.26 / 停 0.52 / 出 0.20），进场从 0.28 倍、偏 −14° 弹冲到 1.14 倍再落回原位，缎带比大字晚一步滑入，退场是放大淡出而不是硬切。**绝不挡翻页**：庆祝还在播的时候按回车或空格照样按建议评分换卡，卡片一隐藏动效立刻停（不会叠到下一张上）。评分、建议与排程完全不受这两个开关影响。样片与探针工具一律调用 `motion_view.badge_centre`，不许自己抄一个分数。

**卡片在屏期间直接打英文。** 拼写、填空、听写的字母格，以及选择题的 A–D、答案面的 A–E/F/P 都是字母键，而中文输入法会把它们接走。插件在卡片出现时把**本进程的键盘布局临时切成美式英文**，卡片收起或关闭时还原——这是每线程、可逆的，不写任何系统或用户设置，也不影响其他窗口。老式非 TSF 输入法另外会走一次"关输入法开关"的路径（微软拼音这类 TSF 引擎不认那个开关，所以布局切换才是真正起作用的杠杆）。若系统里装不出英文键盘布局，插件保持原样不报错。

拼写题的建议评分按提示的**种类和位置**计：一次写对且没用任何提示 → 建议「已掌握」（按 E 或回车即标记并停止学习）；只听了 1 遍发音 → 仍建议「很容易」，2 遍 → 「记住了」，3 遍及以上 → 「困难」；用空格提示字母则按位置加权（第 i 个字母价值 1/i）算出"这个词已经给出多少"，≤20% 建议「很容易」、≤40%「记住了」、≤70%「困难」、更多「再练一次」——所以 14 个字母的词提示首字母是「记住了」，5 个字母的词提示首字母是「困难」，只提示结尾字母几乎不影响。释义/例句提示仍按「困难」计。听写题的「音标」提示同样按用过提示计（2026-11-06 定）：音标几乎能把单词拼出来，看过之后这一题就不再是听写题，所以建议必须掉到 Hard；一次卡片只给一次，按钮随即置灰，点按钮或按 **Shift+空格** 走的是同一条路（同一个控件、同一份计数）。笔记里没有音标字段的词（抽样约 8%）根本不出现这个按钮。其他题型仍按"用过提示即困难"计。答错、错字母、提交未全对各自继续往下压一档，取最严的一档；答错或直接查看答案按“再练一次”。用户可在答对后自行按 A–E 调整。评分直接交给 Anki 原生排程。同组内避免重复同一原形，近期学习过的词有其他候选时暂让位；Anki 的到期状态不变。

答案面上的按键：`A`–`E` 评分、**回车或空格**按建议继续（两个键同义，落地的就是状态行写的那个建议，不再取决于哪个按钮恰好有焦点；回看题目时两个键都不评分，空格还会正常打进字母格）、`Esc` 不评分结束、**`Shift+F` 看回题目**（答案仍算已翻面，再按 `Shift+F` 回到答案；2026-11-06 起看题不再占用单独的 `F`，因为回看题目时按 f 必须能打进字母格而不是把卡片翻回去）、**`P` 回看上一张**（`B` 看更早的一张，`P` 或 `Esc` 退出回看）。回看只显示已经做过并评过分的卡，不发音、不重新评分、不改动 Anki 的排程；退出后回到原来那张卡，输入状态保持不变。回看范围为本次会话最近 10 张。
# 复习计划与例句词形

设置按划词同步、复习提醒、学习计划与考试、卡片显示分区。启用学习时段后，自动提醒只在所选时段出现（至少三行，可添加或禁用时段）；时段须在同一天内且不能重叠，手动复习不受限制。未启用时保留原有电脑使用时长设置。选择四六级笔试时可从中国教育考试网获取日期，网络失败或官方日期过期时请手动设置；雅思、托福等有多场考试，需要手动选择实际日期。

拼写题会将词形表中唯一确定的变化形式还原为原形；存在歧义时保留原词，且不会更改 Anki 笔记。例句提示优先使用笔记中的例句，缺少时按需通过有道查找并遮住目标词形；使用例句提示按辅助作答计分。答案页显示已有近义词、词语辨析，缺少近义词时查询词典；词典释义对照可能包含不同义项，并非自动生成的语义辨析。

选择题可按 A、B、C、D 作答。答案页将形近词、近义词和反义词各限制为最多三个，并优先展示名称包含四六级、四级、六级或 CET 的牌组中的词。释义优先读取本地笔记，缺少时通过有道查询；形近词按本地 LemmInflect 词表匹配，缺失的近反义词来自 [Free Dictionary API](https://dictionaryapi.dev/)（词典内容来源见 [Wiktionary](https://en.wiktionary.org/)）。词语关系可能不适用于当前义项；联网查询会发送相应单词，无结果时不编造释义。

卡片右上角「⋯ → 卡片设置」可选择固定每组张数，或按每日目标自动分组；可设置截止日期和预计每天使用电脑的小时数。截止日期按含当天计算，建议新词数按剩余新卡和今天首次学习的卡片估算；到期数读取 Anki 当前数据，未来复习量并非预测。每日目标统计今天已回答过的不同卡片，包括 Anki 主界面中的学习；到达目标后仍可手动启动复习。Anki 自身的每日上限仍然有效。

例句填空使用 [LemmInflect 0.2.3](https://github.com/bjascob/LemmInflect) 的词形与原形表匹配句中形式，答案页同时显示词条原形；词形关系不保证词义和语境完全一致。词形表来源于 NIH SPECIALIST Lexicon，随插件附带 MIT 许可证。词根和识记方法优先显示笔记中已有的字段；笔记没有时，读随插件附带的 `lexicon/mnemonics.tsv`（2939 个词的前缀/词根拆解与记忆法，来自 BSD-3-Clause 的 english-vocabulary-KyleBing 数据集，见 THIRD-PARTY-NOTICES.md 与 `lexicon/KYLEBING_LICENSE`）。**表里没有的词就什么都不显示**，不留空框也不由模型编造——词源类内容编错一条就是教错一条。《六级全表》实测覆盖率 **2615 / 5211 = 50.2 %**（全量统计，不是抽样）。

复习弹窗可在“卡片显示与朗读 → 弹窗主题”切换浅色和深色。补充牌组使用已有 Anki 卡片，不会自动导入词库；新卡数量仍受对应牌组的 Anki 每日新卡额度限制。

复习提醒支持同时勾选多个补充牌组；参与抽取的卡片需要使用所选笔记类型和单词、释义字段。设置页跟随 Anki 主题。设置考试日期后，Anki 首页显示倒计时、今日计划和近 28 天已学习卡片数（按本地自然日统计；计划数字为估算，Anki 额度仍生效）。主程序复习时会为所选牌组中使用该模板的卡片应用同一视觉风格。

“练习形式”可选择听音拼写：自动朗读单词原形，重复播放不算提示；查看释义或字母提示会影响本次评分。旧词条中误存为字符串列表的释义会在复习窗口自动整理显示，原笔记内容保留。

“练习形式”支持同时勾选英文选中文、中文选英文、释义拼写、例句填空、听音拼写及单词释义判断。随机使用符合当前卡片条件的已选形式；例句不足或安全干扰项不足时，不会切换到未选题型。选择题从现有牌组词条生成候选，参考词性、形近程度及释义排除明显近义和重复，仍可能存在语义歧义。

卡片眉标的第三个词写明这张卡在 Anki 排程里的位置：「新词」是第一次遇到、还没排过间隔；「刚学过」是之前见过但答错、还在学习步长里的词；「到期复习」是已经毕业、按 Anki 算出的间隔到期的词。2026-11-06 之前这两种都写作「到期复习」，于是昨天只见过一次的词看起来像很久以前学过的老词。悬停眉标可看这句解释；间隔和到期时间始终由 Anki 的 FSRS 决定，插件不改动排程。

设置页的「答案面显示例句」默认开启；关掉后答案面不再排词典例句和权威例句卡片，答案面随之变矮。两处不受这个开关影响，是有意为之：例句填空的题目本身就是例句，关掉会把题面吃掉；题目面的「例句」提示按钮是你主动要的，看过照常计入提示。一组结束却什么都没能弹出时，提示会报出被挂起的卡数（如「另有 247 张被你挂起」），不再只说"再勾一本词组"。挂起是你的排程状态，插件只报数，绝不替你取消。

### 这套做法到底有没有效：三个可核对的量

插件的评分建议是**手调权重**（错误字母数、检查失败次数、字母提示按位置加权、题型乘子），不是拟合出来的；每日计划也只是"剩余量 ÷ 距截止日天数"的算术，不含遗忘模型。为了让这两件事可被推翻，插件加了三个只读的量：

- **评分对照日志**：每次评分写一行 `review graded: suggested=… chosen=… mode=… audio=… other=… letters=… boxes=…`。答错被强制 Again 的会标 `forced=again`，不算推翻。`python tools/analyze-grading-agreement.py` 汇总接受率与推翻方向（样本 <40 条时只报数、不下结论）。
- **复习质量报告**：工具 → 单词随身复习 → 生成复习质量报告（只读）。它按被要求的间隔分桶统计到期作答的 Again 率，算出**实测保持率**，与牌组里 `desiredRetention` 的承诺值并排写出；同时统计「已掌握」挂起卡最后一次作答距今多久。空样本一律写"还没有可统计的正式复习答案"，不打印 100%。学习步长（间隔 <1 天）的作答不计入长期保持率，`ease=0` 的系统行也不计入。Anki 没开或不想动 UI 时，可用 `python tools/build-quality-report-from-db.py` 读同一个结果（只读；忙时自动退回快照副本）。
- **每日额度的两套数**：报告第三节逐牌组列出 Anki 的 `new/day` 与今日实际引入数。若出现"引入 > 额度"，原因是**插件用 findCards 挑卡、answerCards 打分，不经过复习队列，所以牌组的每日新词额度拦不住它**——这是事实陈述，插件不会为了数字好看去改你的牌组配置。

「已掌握」按钮现在有两种语义，设置页可选：**挂起**（默认，与历史一致，不再出现、随时可恢复、不写评分）或**按 Easy 评分**（把同一个判断交给调度器，词留在排程里只是被推远，间隔由 Anki 的 FSRS 决定）。挂起与间隔重复的前提相反——被挂起的卡永远不会再被检验；但切换开关**不会动你已经挂起的任何一张卡**，报告只会把它们的清单和"多久没被检验"列出来，恢复与否由你决定。

### 四六级核心词与口语回忆

在“工具 → 单词随身复习 → 词书与词表管理 → 四六级核心词：补充缺失词汇”，插件会保留现有笔记及复习记录，只将缺失且取得释义的词加入“四六级核心词汇”牌组；网络不可用时未取得释义的词可稍后重试。“查看词表”可浏览当前已有的核心词。词表来自社区六级词频整理，经词形核对后保留 481 词，其中 364 词与 ECDICT 四级词表重合；这不是官方真题频率排名。设置中可关闭核心词优先。抽词顺序是每组前 20 % 名额给到期卡、其余给当日新词（2026-11-06 起；此前是先把当天新词额度做完再抽到期），任一队列为空时名额自动让给另一个，到期卡不足也不会硬凑。

复习形式中可勾选“口语回忆”：看中文说出英文，再听答案并自行选择 Anki 评分。此功能不录音、不进行语音识别。部分词有经核对的“拆分记忆”；没有可靠拆解的词不会自动猜测。插件没有内置标注为四六级真题的例句，普通词典例句不能视为真题。

答案面显示词表归属：四级/六级标记来自 ECDICT 词表，六级社区核心标记来自上述社区高频整理；它们表示相应数据集收录，并非官方认证，也不表示词条所有释义都属于考试重点。尚未收录或词形不能可靠还原的单词不显示推测标签。

长单词答案面还会展示按 Moby 音节词表整理的分段；词表未收录的词用完整版 Moby 列表和经词典核对的补充条目补齐，没有任何音节来源的词不显示分段（2026-11-10 起取消了按字母机械分块）。音节分段并非词根词缀，只有经整理的词条才显示词根含义。笔记中已有的词根、识记方法和形近词仍优先保留。

### 六级独立词书与听力模拟

在“工具 → 单词随身复习 → 词书与词表管理 → 六级词书：建立核心与完整词书”会以标签组织现有笔记，保留原有牌组和 Anki 学习记录，只为缺失的词新建笔记。核心词书来自社区六级核心词表；完整词书以 ECDICT 衍生词表为基础，另外包含核心词书的补充词，并非官方考试大纲的完整性认证。两个词书可在同一个子菜单里分别浏览，并可在“工具 → 单词随身复习 → 切换词书”中选择，跨原有牌组学习。重复运行整理不会有意创建重复笔记。

插件在“工具”菜单里只占两项：“全局划词入 Anki 设置…”和“单词随身复习”子菜单（子菜单内是立即弹出一张、切换词书、六级听力，以及低频的词书与词表管理）。

“工具 → 六级听力：本地真题与模拟”提供原创长对话、篇章和讲座式单选题，使用 Anki 系统英语语音朗读。模拟题不是历年真题；若用户在插件用户数据目录中放入经校验的本地题目和录音，也可离线练习。本项目安装包不附带真题音频和题目。听力练习结果不会写入单词卡的 Anki 评分。

听力练习窗口中的“在线真题”按钮打开南京大学的六级历年真题自测页面；题目、音频和计分由该网页提供，联网使用，练习记录不写入插件或 Anki。

### 四级和六级词书入口

顶部工具栏提供“四级词书”和“六级词书”入口；在 Anki 中已有相应标签的卡片时，点击可切换词书并开始弹窗复习。两书的共有词可以共用卡片和进度；原生牌组不会因此自动拆分。对应词表是用户本地导入的 KyleBing 资料，安装包不包含该词表，也不会在新电脑上自动导入；没有相应卡片时入口会提示。学习计划仍受 Anki 每日新卡和复习额度限制。

一组练完会在卡片窗口内出现倒计时面板：**按 Enter 进入下一组学习**（点一下同样有效）；什么都不按就结束本次学习，不会自动续下一组。长单词拼写输入框会分行显示。
