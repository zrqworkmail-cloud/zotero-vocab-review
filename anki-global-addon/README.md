# Anki 全局划词收词

这是现有 Zotero 划词同步项目配套的 Anki 桌面端附加组件。Anki 运行时，它可在 Windows 其他应用中捕获选区，并通过 AnkiConnect 写入 Anki；不需要另外安装 .NET 或常驻托盘程序。

## 安装

将 `zotero_global_capture` 文件夹复制到 Anki 用户配置目录下的 `addons21`，例如：

`%APPDATA%\Anki2\addons21\zotero_global_capture\__init__.py`

重启 Anki。在“工具”菜单打开“全局划词入 Anki 设置…”。设置页可点击快捷键框并录入自定义组合键；至少需要 Ctrl、Alt、Shift 或 Win 中的一个。支持字母、数字、F1–F24 和常用导航键。保存后会立即重新注册。需要 AnkiConnect 正在运行（默认地址 `127.0.0.1:8765`）。

## 三种收词方式

- **选中后按快捷键添加**：在任意可复制文本中选择单词或短语，按设置页中的快捷键（默认 `Ctrl+Shift+F10`）。
- **选中后自动添加**：设置为自动模式；鼠标拖选结束时尝试复制并添加。此模式会监听全局鼠标拖选，可能与拖动界面元素冲突；受保护或禁止复制的应用无法捕获。
- **快捷键预览释义，再按一次添加**：默认模式。选中文本并按快捷键后显示释义预览，再按一次快捷键或点“添加到 Anki”确认；取消、关闭或超时都不会添加。

捕获选区需要临时模拟 `Ctrl+C`。组件会暂存并尝试恢复剪贴板内容；某些应用自定义格式或同时有其他程序更新剪贴板时，无法保证所有剪贴板格式和所有应用行为完全一致。选区只向有道词典查询单词释义，文献上下文不会发送。

默认写入牌组“文献单词”、笔记类型“四六级单词模板”，正面字段“正面”、释义字段“解释”。支持的同名可选字段会补入词性释义、例句、权威例句、词根、近义词、音标和发音链接；已有非空字段不覆盖。重复收录会更新“全局划词收录次数”，并给笔记加上 `anki_global_capture` 标签。

## 单词随身复习

Anki 在后台运行时，附加组件默认每 30 分钟在屏幕右下角弹出一张单词卡。它优先挑选到期词，并在牌组当日新词额度允许时选取新词。选择题与英文填空默认混合；核对答案后选择“再练一次”“记住了”或“很容易”，结果才写入 Anki。关闭或选择“稍后再说”不会评分。

在“工具 → 全局划词入 Anki 设置…”可以暂停提醒，调整间隔、位置和题型，开关 Anki 内单词卡美化，以及选择 Windows 登录时启动 Anki 后台复习。该开机启动选项默认关闭；启用后仅为当前 Windows 用户添加启动项，关闭选项会移除它。也可以通过“工具 → 单词随身复习：立即弹出一张”随时打开复习卡。

桌面卡片样式只作用于设置中指定的牌组和笔记类型，不修改 Anki 笔记类型或其他牌组的模板。弹窗需要 Anki 和 AnkiConnect 运行；缺少释义的卡片不会被用作选择题或填空题。
