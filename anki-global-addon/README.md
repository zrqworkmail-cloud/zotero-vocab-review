# Anki 全局划词收词

这是现有 Zotero 划词同步项目配套的 Anki 桌面端附加组件。Anki 运行时，它可在 Windows 其他应用中捕获选区，并通过 AnkiConnect 写入 Anki；不需要另外安装 .NET 或常驻托盘程序。

## 安装

在 Anki 中通过“工具 → 附加组件 → 从文件安装”选择 `zotero_global_capture.ankiaddon`，或双击该文件安装。也可以将 `zotero_global_capture` 文件夹复制到 Anki 用户配置目录下的 `addons21`，例如：

`%APPDATA%\Anki2\addons21\zotero_global_capture\__init__.py`

重启 Anki。在“工具”菜单打开“全局划词入 Anki 设置…”。设置页可点击快捷键框并录入自定义组合键；至少需要 Ctrl、Alt、Shift 或 Win 中的一个。支持字母、数字、F1–F24 和常用导航键。保存后会立即重新注册。需要 AnkiConnect 正在运行（默认地址 `127.0.0.1:8765`）。如果未安装且没有可用连接，组件会通过 Anki 自带的 AnkiWeb 下载器自动安装官方 AnkiConnect；首次安装完成后需要重启 Anki。已有安装不会被覆盖或强制启用。

## 三种收词方式

- **选中后按快捷键添加**：在任意可复制文本中选择单词或短语，按设置页中的快捷键（默认 `Ctrl+Shift+F10`）。
- **选中后自动添加**：设置为自动模式；鼠标拖选结束时尝试复制并添加。此模式会监听全局鼠标拖选，可能与拖动界面元素冲突；受保护或禁止复制的应用无法捕获。
- **快捷键预览释义，再按一次添加**：默认模式。选中文本并按快捷键后显示释义预览，再按一次快捷键或点“添加到 Anki”确认；取消、关闭或超时都不会添加。

捕获选区需要临时模拟 `Ctrl+C`。组件会暂存并尝试恢复剪贴板内容；某些应用自定义格式或同时有其他程序更新剪贴板时，无法保证所有剪贴板格式和所有应用行为完全一致。选区只向有道词典查询单词释义，文献上下文不会发送。

默认写入牌组“文献单词”、笔记类型“四六级单词模板”，正面字段“正面”、释义字段“解释”。支持的同名可选字段会补入词性释义、例句、权威例句、词根、近义词、音标和发音链接；已有非空字段不覆盖。重复收录会更新“全局划词收录次数”，并给笔记加上 `anki_global_capture` 标签。

## 单词随身复习

Anki 在后台运行时，附加组件默认每 30 分钟在屏幕右下角弹出一张单词卡。它会先从主牌组和可选的补充牌组中挑选到期词，若没有可复习的到期词，再按各牌组的当日新词额度选取新词。默认补充牌组为“四六级单词”（不存在时跳过），可在设置中修改。收录过的词及其他牌组中同词的卡片获得更高抽取权重，收录词的抽取权重上限为普通词的 2 倍；权重不会改变 Anki 的到期时间。默认每 5 分钟额外检查 Anki 的到期队列，若有到期词会提前提醒；新词仍按正常间隔出现。这项“记忆复习”可在设置中关闭。默认每轮连续复习 3 张，可改为 1–10 张；选择题支持英文选中文和中文选英文，填空支持释义拼写和有合适例句时的例句挖空。拼写题每个字母一个输入格，输入时即时显示对错；可逐步增加字母提示并继续尝试，点击“显示答案”才揭晓。选择题显示明显的正确或错误反馈。每张卡核对后选择“再练一次”“困难”“记住了”或“很容易”，结果才写入 Anki；关闭或选择“稍后再说”不会评分。

在“工具 → 全局划词入 Anki 设置…”可以从已有牌组、笔记类型和字段的下拉菜单中选择配置，也可以暂停提醒，调整间隔、每组数量、位置和题型，设置单词及普通、权威或全部例句在揭晓后自动朗读，开关 Anki 内单词卡美化，以及选择 Windows 登录时启动 Anki 后台复习。该开机启动选项默认关闭；启用后仅为当前 Windows 用户添加启动项，关闭选项会移除它。也可以通过“工具 → 单词随身复习：立即弹出一张”随时打开复习卡。

桌面卡片样式只作用于设置中指定的牌组和笔记类型，不修改 Anki 笔记类型或其他牌组的模板。弹窗需要 Anki 和 AnkiConnect 运行；缺少释义的卡片不会被用作选择题或填空题。

单词默认在答案揭晓后自动朗读；例句可选择逐句或全部手动朗读，也可选择自动朗读普通例句、权威例句或全部例句。发音使用 Anki 的系统文字转语音（TTS），不下载 MP3；可用声音取决于系统和 Anki。到期时间与评分继续使用用户现有的 Anki 排程，插件不会擅自启用 FSRS 或修改其他牌组的设置。

复习卡右上角的“...”可打开设置、查看评分机制和访问 Zotero 配套插件介绍。例句中的英文单词可点击查询、添加或查看已有卡片；已收录词可选择下划线、加粗或不标记。轻微失误后答对可建议“困难”，较多失误或提示则建议“再练一次”；答错或直接查看答案按“再练一次”。用户可在答对后调整建议评分。评分直接交给 Anki 原生排程。同组内避免重复同一原形，近期学习过的词在有其他候选时暂让位；Anki 的到期状态不变。
# 复习计划与例句词形

设置按划词同步、复习提醒、学习计划与考试、卡片显示分区。启用学习时段后，自动提醒只在所选时段出现（至少三行，可添加或禁用时段）；时段须在同一天内且不能重叠，手动复习不受限制。未启用时保留原有电脑使用时长设置。选择四六级笔试时可从中国教育考试网获取日期，网络失败或官方日期过期时请手动设置；雅思、托福等有多场考试，需要手动选择实际日期。

拼写题会将词形表中唯一确定的变化形式还原为原形；存在歧义时保留原词，且不会更改 Anki 笔记。例句提示优先使用笔记中的例句，缺少时按需通过有道查找并遮住目标词形；使用例句提示按辅助作答计分。答案页显示已有近义词、词语辨析，缺少近义词时查询词典；词典释义对照可能包含不同义项，并非自动生成的语义辨析。

选择题可按 A、B、C、D 作答。答案页将形近词、近义词和反义词各限制为最多三个，并优先展示名称包含四六级、四级、六级或 CET 的牌组中的词。释义优先读取本地笔记，缺少时通过有道查询；形近词按本地 LemmInflect 词表匹配，缺失的近反义词来自 [Free Dictionary API](https://dictionaryapi.dev/)（词典内容来源见 [Wiktionary](https://en.wiktionary.org/)）。词语关系可能不适用于当前义项；联网查询会发送相应单词，无结果时不编造释义。

卡片右上角「⋯ → 卡片设置」可选择固定每组张数，或按每日目标自动分组；可设置截止日期和预计每天使用电脑的小时数。截止日期按含当天计算，建议新词数按剩余新卡和今天首次学习的卡片估算；到期数读取 Anki 当前数据，未来复习量并非预测。每日目标统计今天已回答过的不同卡片，包括 Anki 主界面中的学习；到达目标后仍可手动启动复习。Anki 自身的每日上限仍然有效。

例句填空使用 [LemmInflect 0.2.3](https://github.com/bjascob/LemmInflect) 的词形与原形表匹配句中形式，答案页同时显示词条原形；词形关系不保证词义和语境完全一致。词形表来源于 NIH SPECIALIST Lexicon，随插件附带 MIT 许可证。词根和识记方法仅显示笔记中已有的对应字段，不自动编造内容。

复习弹窗可在“卡片显示与朗读 → 弹窗主题”切换浅色和深色。补充牌组使用已有 Anki 卡片，不会自动导入词库；新卡数量仍受对应牌组的 Anki 每日新卡额度限制。

复习提醒支持同时勾选多个补充牌组；参与抽取的卡片需要使用所选笔记类型和单词、释义字段。设置页跟随 Anki 主题。设置考试日期后，Anki 首页显示倒计时、今日计划和近 28 天已学习卡片数（按本地自然日统计；计划数字为估算，Anki 额度仍生效）。主程序复习时会为所选牌组中使用该模板的卡片应用同一视觉风格。

“练习形式”可选择听音拼写：自动朗读单词原形，重复播放不算提示；查看释义或字母提示会影响本次评分。旧词条中误存为字符串列表的释义会在复习窗口自动整理显示，原笔记内容保留。

“练习形式”支持同时勾选英文选中文、中文选英文、释义拼写、例句填空、听音拼写及单词释义判断。随机使用符合当前卡片条件的已选形式；例句不足或安全干扰项不足时，不会切换到未选题型。选择题从现有牌组词条生成候选，参考词性、形近程度及释义排除明显近义和重复，仍可能存在语义歧义。

### 四六级核心词与口语回忆

在“工具”菜单选择“四六级核心词：补充缺失词汇”，插件会保留现有笔记及复习记录，只将缺失且取得释义的词加入“四六级核心词汇”牌组；网络不可用时未取得释义的词可稍后重试。“查看词表”可浏览当前已有的核心词。词表来自社区六级词频整理，经词形核对后保留 481 词，其中 364 词与 ECDICT 四级词表重合；这不是官方真题频率排名。设置中可关闭核心词优先，Anki 到期复习始终先于新词。

复习形式中可勾选“口语回忆”：看中文说出英文，再听答案并自行选择 Anki 评分。此功能不录音、不进行语音识别。部分词有经核对的“拆分记忆”；没有可靠拆解的词不会自动猜测。插件没有内置标注为四六级真题的例句，普通词典例句不能视为真题。

答案面显示词表归属：四级/六级标记来自 ECDICT 词表，六级社区核心标记来自上述社区高频整理；它们表示相应数据集收录，并非官方认证，也不表示词条所有释义都属于考试重点。尚未收录或词形不能可靠还原的单词不显示推测标签。

长单词答案面还会展示按 Moby 音节词表整理的分段；未收录的长词使用机械拼写分块，并明确标注。音节或拼写分块并非词根词缀，只有经整理的词条才显示词根含义。笔记中已有的词根、识记方法和形近词仍优先保留。

### 六级独立词书与听力模拟

“工具 → 六级词书：建立核心与完整词书”会以标签组织现有笔记，保留原有牌组和 Anki 学习记录，只为缺失的词新建笔记。核心词书来自社区六级核心词表；完整词书以 ECDICT 衍生词表为基础，另外包含核心词书的补充词，并非官方考试大纲的完整性认证。两个词书可在“工具”菜单分别浏览，并可在插件设置的“复习词书”中选择，跨原有牌组学习。重复运行整理不会有意创建重复笔记。

“工具 → 六级听力：本地真题与模拟”提供原创长对话、篇章和讲座式单选题，使用 Anki 系统英语语音朗读。模拟题不是历年真题；若用户在插件用户数据目录中放入经校验的本地题目和录音，也可离线练习。本项目安装包不附带真题音频和题目。听力练习结果不会写入单词卡的 Anki 评分。

听力练习窗口中的“在线真题”按钮打开南京大学的六级历年真题自测页面；题目、音频和计分由该网页提供，联网使用，练习记录不写入插件或 Anki。

### 四级和六级词书入口

顶部工具栏提供“四级词书”和“六级词书”入口；在 Anki 中已有相应标签的卡片时，点击可切换词书并开始弹窗复习。两书的共有词可以共用卡片和进度；原生牌组不会因此自动拆分。对应词表是用户本地导入的 KyleBing 资料，安装包不包含该词表，也不会在新电脑上自动导入；没有相应卡片时入口会提示。学习计划仍受 Anki 每日新卡和复习额度限制。

答题评分写入后自动继续下一组；窗口上方会短暂提示，Esc 可退出。长单词拼写输入框会分行显示。
