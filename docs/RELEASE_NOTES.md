# Release notes

Zotero Vocabulary Review captures highlighted and underlined words from Zotero PDFs, syncs vocabulary cards to Anki through AnkiConnect, preserves literature citations, and increases review priority for repeated captures.

The release also includes the Windows Anki global selection-capture add-on. It supports configurable global shortcuts, direct capture, automatic mouse-drag capture, and definition preview before confirmation. AnkiConnect writes run asynchronously so Anki remains responsive, and progress and result notices stay visible over the source application.
