## Persona

**周**，在读研究生，同时备考六级（2026-12-12）和读英文文献

- **情境**：每天碎片时间点开弹窗卡背词
- **目标**：选一个范围就开始学，学的过程中始终知道自己在学什么、还剩多少
- **当前 workaround**：打开 Anki → 点开始学习 → 凭记忆判断当前配置是不是想要的；不对就进设置重拼牌组和标签，拼完还是不确定，于是放弃改配置、硬着头皮背
- **挫败感**：设置里六个东西都能影响"学什么"，没有一个有名字；词书/牌组/标签三个概念混着用；配置里存的牌组已被删除而自己不知道；背完一组仍不知道"六级核心"学了几个
- **"完成"长什么样**：像墨墨那样，点一下词书，屏幕上一直写着词书名和进度，不用想

## 商业角度

- **为什么是现在**：考试日期 2026-12-12 固定，剩 42 天；范围模型不对，每天的时间都在决策疲劳上漏掉
- **谁付费**：用户自己的时间
- **商业化**：无——自用工具
- **战略意图**：retention（让他每天真的打开并且不中途放弃）

## 桌上的方向

**方向 A — 词书＝一个有名字的标签视图**
主界面一排词书卡（六级核心 / 六级全表 / 四级核心 / 四级全表 / 文献单词），点一张就是"正在学它"；卡片顶部和主界面常驻 `六级核心 · 今日 12 · 已学 128/439`。**删掉**牌组多选、标签多选、标签匹配、不限牌组、范围名称五个控件。
- 用户价值：选范围从"拼六个控件"变成"点一张卡"；进度常驻；改完设置立刻能从名字看出生效没有
- 商业价值：净减法——删掉一整层组合逻辑（scope_decks / scope_tags / tags_match / all_decks / scope_name）
- 最高风险假设：他愿意放弃自由组合——**已确认**（"不要拼，给我菜单"）
- 解决：机会 #1 #2 #3 #4

**方向 B — 预设 + 高级两层**
默认只见词书菜单，展开"高级"才露牌组+标签控件。
- 优点：改动最小、风险最低
- 最高风险假设：他真会用高级层——**证据相反**，且这一层就是混乱源头
- 解决：#1 #2

**方向 C — 模型不动，只加显示**
卡片顶部横幅 + 开始前确认页显示范围名和数量。
- 最高风险假设：问题只在显示不在模型——**不成立**，他每次仍得自己拼一遍
- 解决：#1 #3

## 我押

**方向 A**。三个理由：

1. **机会匹配最强**——#1 #2 #3 三个高优先级机会一次全解，B 漏 #3 #4，C 漏 #2 #4。
2. **风险/收益最好**——A 是删代码不是加代码。当前那层组合控件正是"屎山"的成因，保留它（B）等于把根因藏进折叠面板。
3. **有现实先例**——墨墨用"词书是视图 + 只背此书开关"跑了十几年，且它留下的空白（把自己的收藏当词书）恰好只有本项目能做。

## 关键假设

1. **（已替你拍定，可退回）**"正在学一个范围"时，其他范围的到期复习词要不要照样弹。默认取**只学当前范围**（对齐墨墨"只背此书"），跨范围到期词在主界面给一条不阻断的提示。
2. 词书菜单的项必须由标签**自动发现**（`zvr_` 前缀 + 笔记数非零），不能写死——写死就会重演"词书下拉写死在源码里"那一类 bug。
3. "已学 N / 总 M" 的"已学"口径要定义清楚：是"该范围内 reps>0 的卡"，还是"该范围内已度过学习期的卡"。这两个数差很多，选错会让进度看起来假。
